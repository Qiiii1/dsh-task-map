# 任务地图 · DeepSeek Harness 插件

任务地图把 DeepSeek 会话中的待办渲染成可编辑的节点画布；整段会话的历史任务都会保留，每一轮对话是一段（任务 01、任务 02…），段内按待办顺序连成步骤链。交互参考 [Topic Explorer](https://github.com/Qiiii1/topic-explorer)。

## 安装

在 DeepSeek Harness 的「插件 → 添加插件」中，选择本地目录并填入本项目 `deepseek-task-map` 的绝对路径。若目录缺少 `dist/client.js`，先在该目录运行 `npm run build`。已构建的目录无需安装 npm 依赖。启用插件后，在标准模式会话页的「对话」旁打开「任务地图」。

也可以执行 `npm pack` 构建本地安装包，然后使用 Harness CLI 安装到对应配置。桌面端使用 `desktop` 配置，Web CLI 默认使用 `web` 配置。

```sh
dsh plugin --profile desktop add /absolute/path/to/dsh-task-map-0.1.0.tgz
```

本版基于 Harness 0.2.2-rc.2 的 Web Client 与 Session 接口。

## 使用

1. 在标准模式会话布置多步骤任务，每发一条新消息就会在画布上开启一段新任务；同一段内 DeepSeek 更新待办时，步骤就地更新。想先审阅计划，可以在任务里请 DeepSeek 写入待办后先等待指示。若尚无待办，地图中可点击「请求规划」。
2. 点击卡片查看上游和直接后续，拖动卡片调整位置（挡路的卡片会实时让开，松手后停在新位置）；拖动画布空白处可平移，底部按钮可以缩放、适配全图，中间的「方块」按钮在画布中央添加一个手动方块，准星按钮会把视角居中到正在进行的卡片（没有则取最新一段的最后一步），并把和它相关的步骤、方块按依赖距离散在四周，其它任务的起点卡留在最外圈；点「适配画布」回到完整布局。卡片获得焦点后可用方向键微调位置。
3. 双击方块或卡片，详情面板会直接聚焦 Guide 输入框；也可以先选中卡片再填写。把方块右侧的小手柄拖到需要引导的步骤上，即建立「方块 → 步骤」的引导关系（详情面板的「前置依赖」也能改）。
4. 在节点详情填写 Guide，按需附上图片、勾选「认可上游步骤」，再发送。Guide 会作为用户消息（含图片）进入当前会话。任务运行中使用 Harness 的 Steer，把 Guide 送入下一步；空闲时发送会开始下一轮。正在执行的步骤会以闪烁标记提示。
5. 回答进行中，被引导的步骤会标为「回答中」并闪烁；回答结束后，若开启了「回答结束后自动标完成」，该步骤自动变为已完成（详情面板可一键撤销，顶部的三个状态按钮也能手动切换）。正在执行的待办步骤同样闪烁；一段任务结束（或换到下一轮）后，上一段里残留的「进行中」会按未完成处理，不会一直闪。
6. 点击右上角的 token 指标查看会话累计输入、输出和缓存计数。用量读取 Harness 的供应商报告值，统计范围是当前会话。

每段任务从起点卡片开始，步骤按顺序向右推进，一行放不下时蛇形折到下一行（行尾垂直向下接下一行行首），连线上的小箭头指向下一步；手动方块挂在其目标步骤下方。段与段左对齐、自上而下按时间先后排列，段与段之间用纵向虚线箭头串起来；最新一段的起点卡片会标出「· 当前」，打开地图时整张图会适配窗口（只有一段时保持可读的缩放）。段与段之间会用虚线标出「这一轮参考了哪一段」：插件从每条新消息里提取文件路径、引号里的引用，以及「继续 / 刚才 / 上一段」这类承接词，与更早的段落比对后连到最近的来源；起点卡片下方的「↩ 任务 0X」徽章可以点，视角会跳到被引用的那一段。默认连线按待办列表顺序生成。节点的执行状态读取 Harness 的 todos 投影（与框架待办面板同一份实时数据），本地手动修改优先。画布位置、手动加点和编辑保存在本机的当前浏览器或桌面客户端，按会话和任务隔离。节点 Guide 发送前的画布改动保存在本地，目标与相关上下游内容会随 Guide 送入会话。如果 DeepSeek 改写了原待办的文字，该待办会作为一个新节点出现。

## 构建

```sh
npm run build
npm pack
```
